# Bank Loan Analysis Report
## Project Overview
This project focuses on analyzing bank loan data using Python to understand
loan applications, funded amounts, repayment behavior, loan quality, and
customer/loan characteristics.

## Business Objective
- Analyze overall loan application and funding trends
- Understand good loans vs bad loans
- Identify factors associated with loan performance
- Analyze loan status, purpose, grade, income and other customer attributes
- Generate business insights to support lending decisions

## Dataset
The project uses a bank loan dataset containing information about loan
applications, funded amounts, loan status, borrower characteristics,
loan purpose and repayment-related attributes.
